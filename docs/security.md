# Безопасность и обработка ошибок

| Риск | Мера в проекте | Сценарий проверки |
|---|---|---|
| Перехват сетевого трафика | HTTPS, локальный интерфейс, проверка отпечатка сертификата встроенного сервера | Проверить адрес и сертификат при запуске |
| Утечка паролей из базы | PBKDF2 SHA-256 со случайной солью на запись | Посмотреть формат поля PasswordHash |
| Перебор паролей | Лимит попыток входа для IP | Отправить больше пяти попыток в минуту |
| Подделка токена | Проверка подписи, срока, издателя и аудитории | Изменить JWT и получить 401 |
| Превышение прав роли | Политики API и серверная фильтрация заказов | Выполнить запросы из матрицы доступа |
| Повтор сеанса или закрытый вход | Отзыв JWT при выходе и проверка активности учётной записи | Повторить запрос после выхода или отключения |
| SQL-инъекция | EF Core и параметризованные запросы | Передать специальный текст в строку поиска |
| Формула в выгрузке CSV | Экранирование текстовых значений с формульным префиксом | Экспортировать значение с начальным знаком «=» |
| Чрезмерный размер импорта | Максимум 1 МБ и 5000 заказчиков | Передать файл, превышающий лимит |
| Раскрытие внутренней информации | Глобальный Problem Details без стека и SQL в ответах | Обратиться к API при недоступной базе |

| Событие | Ответ | Действие пользователя |
|---|---|---|
| Недопустимые данные или CSV | 400 | Исправить поля или указанные строки |
| Проблема с логином или JWT | 401 | Проверить учётные данные или начать новый сеанс |
| Запрещённое действие | 403 | Использовать разрешённую операцию |
| Отсутствующая или чужая запись | 404 | Обновить список |
| Устаревшая версия заказа или занятый логин | 409 | Открыть свежую карточку или выбрать другой логин |
| Превышен размер CSV | 413 | Уменьшить размер файла |
| Слишком много попыток входа | 429 | Повторить через минуту |
| База недоступна в запросе к /health | 503 | Проверить путь базы и журналы |

Учебный запуск предназначен для локального рабочего места. При самостоятельной настройке API используйте собственный ключ и учётные записи, ограничьте сетевую доступность и ведите журналы отдельно от исходников.
