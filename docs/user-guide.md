# Руководство пользователя

Порядок запуска и учебные логины приведены в [README](../README.md).

## Заказы

1. Откройте «Заказы». Введите часть названия, параметров, имени заказчика, телефона, ссылки на макет или номер заказа. Для поиска по точному номеру можно указать `#4`.
2. Выберите статус в выпадающем списке. Таблица обновится сразу. Чтобы снять фильтр, выберите «Все статусы». Очистка поля поиска убирает текстовый фильтр.
3. Для создания заказа менеджер или администратор нажимает «Новый заказ». Укажите заказчика, продукцию, параметры печати и тираж. Дополнительно можно указать макет, печатника, сумму и срок выдачи.
4. Выберите строку. «Карточка» показывает детали, «Редактировать» открывает форму, «Сменить статус» предлагает доступные переходы. Перед согласованием сохраните ссылку или имя файла макета, перед печатью назначьте печатника, перед выдачей укажите сумму и срок.
5. Печатник выбирает свою строку со статусом «Печать» и переводит её в «Готов». На вкладке «Статистика» он видит показатели по назначенным заказам.

## Справочник и файлы

На вкладке «Заказчики» можно добавить или изменить запись, а также выбрать файл через «Импорт CSV». После импорта появляется число записей или список строк для исправления. В разделе заказов кнопки CSV, JSON и XML сохраняют текущую выборку через диалог выбора файла.

## Сотрудники

Администратор открывает «Пользователи», добавляет учётную запись и выбирает её роль. Для существующей строки доступны «Закрыть вход» и «Разрешить вход». Доступ своей записи изменить нельзя. Чтобы сменить рабочую роль, нажмите «Выйти» и войдите под другой учётной записью.
