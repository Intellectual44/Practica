# Артефакты и обмен файлами

| Артефакт | Источник | Получатель | Формат |
|---|---|---|---|
| Учётные данные | Форма входа | API | JSON по HTTPS |
| JWT | API | WPF | Bearer-заголовок |
| Заказ | WPF, API | API, WPF | JSON по HTTPS |
| Заказчики для импорта | Оператор | API и SQLite | UTF-8 CSV |
| Выборка заказов | SQLite через API | Пользователь | CSV, JSON, XML |
| База и журналы | SQLite, API, WPF | Рабочая станция | DB и LOG |

Импорт читает колонки `Name,Phone,Email` в этом порядке. Разделитель — запятая или точка с запятой. Имя и телефон обязательны, адрес электронной почты при заполнении проверяется. Поля в кавычках могут содержать разделители. При любой ошибке импорт отклоняется целиком, с номерами ошибочных строк. Лимиты — 1 МБ и 5000 записей.

- [Пример корректного CSV](examples/customers.csv)
- [CSV для проверки ошибок](examples/customers-invalid.csv)

В выгрузке передаются идентификаторы, заказчик и телефон, продукция, параметры, примечания, печатник, статус, сумма, срок выдачи, причина отмены, время создания и завершения, версия, тираж и ссылка на макет. В CSV используется UTF-8 с BOM, разделитель — точка с запятой. В JSON — массив заказов, в XML — элементы `Orders/Order`. Суммы используют точку, время — ISO 8601 UTC, срок выдачи — календарная дата. CSV экранирует кавычки и значения, которые электронная таблица может принять за формулы.
